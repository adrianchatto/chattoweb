# Image Assets

## Required Images

### 1. headshot.jpg (400x400px @ 2x = 800x800px)
- Your professional headshot
- Square format, well-lit
- Optimized for web (< 200KB)

### 2. og-image.jpg (1200x630px)
- Social media preview image
- Include your name and title
- Brand colors: Blue accent

### 3. favicon.ico
- 32x32px icon in root /public directory
